# game-template

Template repository for the « Usine à jeux » factory (n8n + Claude agents).
Each game repo is generated from this template.

- Vite + TypeScript + `<canvas>` shell, phone-portrait, touch-first
- `npm run dev` / `npm run build` / `npm test`
- CI: merge to main → GitHub Pages; tag `v*` → debug APK on a GitHub Release
- Agent conventions: see [CLAUDE.md](CLAUDE.md)
